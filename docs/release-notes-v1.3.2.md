# 大肥鱼桌宠 · Android 版 v1.3.2

从 Python / PySide6 桌面版移植而来，Kotlin 原生实现。目标 Android 8.0+（minSdk 26）。

**本版专门针对语音输入的稳定性做优化。**

---

## 安装步骤

1. 下载 `dafeiyu-pet-v1.3.2-release.apk` 安装（首次需允许「安装未知来源应用」）。
2. 打开 → 点「授予悬浮窗权限」→ 在系统设置里打开 **「允许显示在其他应用上层」**。**必须做，否则鱼不会出现。**
3. Android 13+ 再授予通知权限。
4. 点「启动桌宠」。

## 为什么语音会「卡」和「断连」

**根因是架构性的，不是参数问题**：

我原来一直用 `SpeechRecognizer.createSpeechRecognizer()` —— 它默认走**云端识别**：
音频要上传、识别结果要下载。所以：

- 每次说话都要重新建立一个到服务端的连接 → **卡**
- 网络一抖就 `ERROR_NETWORK` / `ERROR_SERVER` → **断连**
- 说一句要等一个来回 → 延迟明显

**靠调参数解决不了这个问题**，得换识别通道。

## 本版 5 项优化

### 1. 优先用「设备端离线识别」（关键）

Android 12+ 提供了 `createOnDeviceSpeechRecognizer()`，**音频不离开手机**：

| | 云端识别（旧） | 设备端离线（新） |
|---|---|---|
| 音频走向 | 上传到服务器 | **不出本机** |
| 网络依赖 | 必需，一抖就断 | **不需要** |
| 连接建立 | 每次都要 | **无** |
| 隐私 | 语音上传 | **完全本地** |

现在**默认优先离线**。这项改动直接去掉了「网络」这个故障源。

### 2. 复用识别器实例

之前**每次按下都 `destroy()` + 重新 `create()`**，等于每次都要重建连接。
现在识别器实例保留复用 —— `stop()` 只结束本次收音，不销毁实例。

### 3. 瞬时错误自动重试

网络抖动、服务端临时抽风、识别器正忙 —— 这些**重试一次往往就好了**。
现在这类错误会退避重试（最多 2 次），并在界面上显示「连接不稳，正在重试」。

而权限、没听清、无匹配这类重试无意义的错误，仍然如实报给你，不会白转圈。

### 4. 静音超时调优

默认的静音超时偏短：你说到一半停下来想一想，就会被系统判定「没听到声音」
而提前结束 —— **这个体感也很像「断连」**。现在给足思考时间，结束时机交给你松手。

### 5. 界面告诉你用的是哪种识别

按住说话时，浮层上的提示会显示：

- 「**离线识别（不耗流量）**」
- 「在线识别」
- 「连接不稳，正在重试（第 N 次）…」

这样"卡"的时候你能看出卡在哪，而不是对着一个转圈猜。

## 设置项

**AI 与账号 → 对话行为 →「优先使用离线识别」**（默认开启）

下面会显示本机的实际能力，例如：

```
本机支持离线识别 ✓（同时可用在线识别）
```

**什么时候该关掉它**：部分机型的离线中文识别准确率一般。
如果你发现识别出来的字不对，可以关掉改用在线识别。

> 如果显示「本机不支持离线识别」，说明系统没装离线识别包。
> 可以在系统设置里下载「离线语音识别」对应语言包，装好后本 App 会自动用上。
