# 大肥鱼桌宠 · Android 版 v1.2.3

从 Python / PySide6 桌面版移植而来，Kotlin 原生实现（纯 View + Canvas 绘制，无第三方 UI 库）。目标 Android 8.0+（minSdk 26）。

---

## 安装步骤

1. 下载下方 `dafeiyu-pet-v1.2.3-release.apk`，拷到手机点击安装（首次需允许「安装未知来源应用」）。
2. 打开应用 → 点「授予悬浮窗权限」→ 在系统设置里打开「**允许显示在其他应用上层**」。
   **这步必须做，否则鱼不会出现。**
3. Android 13+ 再点「授予通知权限」。
4. 点「启动桌宠」。

## 本版修复

### 1. AI 回复变成一大串 `nullnullnull...` ✅ 已修

**现象**：对话中输出一长串 `null`，然后没有任何实际内容。

**根因**：`deepseek-flash` 是**带思考（reasoning）的模型**，流式响应的正文帧长这样：

```json
{"delta":{"content":null,"reasoning_content":"我们需 要"}}
```

注意 `"content"` 是 **JSON 的 null**，而真正的内容在 `reasoning_content` 字段里。

我之前的代码用 `optString("content")` 取值 —— **`org.json` 的 `optString` 遇到 JSON null 会返回字符串 `"null"`**（它只判断 key 存不存在，不做空值判断）。于是每一帧都往气泡里追加一个字面量 `null`，累积成你看到的那一大串。

雪上加霜的是我把 `max_tokens` 设成了 200，而模型思考一次能产生 **73KB** 内容 —— token 全被思考烧光，正文永远是空的。

**修法**：
- 新增 `optStringOrNull()`，用 `isNull()` 区分 JSON null 与空串
- `max_tokens` 提到 2048（开启思考时）
- 单独处理 `reasoning_content`：思考内容以**灰色斜体气泡**显示（正好呼应原 Python 版的「思维链心声」）
- 识别 `finish_reason == "length"`，被截断时明确提示而不是丢个空气泡

### 2. 「思考」开关（新增）

设置页新增「**显示思考过程（思维链）**」，**默认关闭**。

实测数据说明为什么默认关：

| 设置 | 同样一次请求的响应体积 |
|---|---|
| 思考开启 | **81 KB** |
| 思考关闭 | **1.5 KB** |

差 54 倍。关闭时响应快、省 token；开启时能看到鱼"思考"的过程。

## 本版新增：语音输入（按住说话）

对话界面输入框旁新增 🎤 按钮，**按住说话、松开结束**：

- 边说边显示中间识别结果（实时填进输入框）
- 松开后自动发送（可在设置里关掉，改成只填入输入框等你确认）
- 使用系统自带的 `SpeechRecognizer`，**不引入任何第三方语音 SDK、不需要额外 API Key**
- 首次点击会申请麦克风权限

设置页新增「**语音识别后自动发送**」开关。

> **可用性说明**：依赖系统里的语音识别引擎。
> 国产 ROM（小米/华为/OPPO/vivo）通常内置识别服务，可直接用；
> 若设备没有任何识别引擎，按钮会置灰并提示。谷歌服务不可用的设备上
> 走 Google 识别会失败（提示「网络错误，识别失败」）。
