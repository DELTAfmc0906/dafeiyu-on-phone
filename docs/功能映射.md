## 六、屏幕适配（重点）

这是你特别提醒的地方。PC 版按 340px 固定高度画，手机上会**糊住半个屏幕**，所以做了这些改造：

| 维度 | PC 版 | Android 版 |
|---|---|---|
| 角色高度 | 固定 340px × 倍率 | **屏幕高度的 8%~50% 自由可调**（v1.1），默认 20%；三档快捷 10%/20%/34% |
| 移动速度 | 固定 380 px/s | 屏幕高度的 20% /秒（等比缩放，小屏不会显得飞快） |
| 气泡字号 | 11pt 固定 | 气泡预留高度的 26%（随角色大小自适应） |
| 气泡换行 | `QFontMetrics` 逐字测宽 | `Paint.measureText` 逐字测宽（中文无空格，不能用 `breakText`） |
| 窗口尺寸 | 随尺寸档位重建 | 按三种视图里**最宽的一张**定宽，转向时不重建窗口 |
| 安全区 | 屏幕可用区 | 顶部留气泡位置，底部避开导航栏 |
| 喂食按钮 | 44px | 48dp（约手机上 144px） |

### 手机端特有问题：鱼挡住了设置界面

这是移植中实际踩到的可用性问题，v1.1 专门修了：

**现象**：把鱼调到 50% 时窗口是 `1212×1624`，而设置面板自己的控件（比如「可互动」复选框）
位于 y≈1456~1540 —— **完全被鱼盖住**。用户点不到复选框，也就没法把鱼调小，形成死循环。

**修法**：给服务加 `ACTION_SET_TOUCHABLE`，并引入 `PetRuntime.settingsVisible` 标记。
设置面板 `onResume` 时把鱼设为触摸穿透，`onPause` 时恢复用户原本的设置。

**关键细节**：不能只在 `onResume` 里发指令。用户最常见的操作顺序是
「先打开设置面板 → 再点启动桌宠」，那一刻服务还没启动，指令没人接收；
等服务起来时面板已经在前台，没人再告诉它该穿透。
所以服务在**创建悬浮窗时会主动查询** `PetRuntime.settingsVisible`。

### 关键发现：原版的模型名已经失效

原 `桌宠.py` 第 46 行：

```python
DS_MODEL = "deepseek-chat"
```

`deepseek-chat` 与 `deepseek-reasoner` **已于 2025-07-24 停用**。
照抄原代码的话，v1.2 一接入就会 404。现按
[DeepSeek API 官方文档](https://api-docs.deepseek.com/) 改为 `deepseek-flash`

## 八、移植过程中发现并修掉的原版隐患

| 位置 | 问题 | 处理 |
|---|---|---|
| 交叉淡化 | 原版 `draw_one` 用当前 `self.facing` 判断镜像，但旧图是上一帧朝向 | Android 版让每张图带自己的朝向 |
| 进食动画 | 原版 `on_food` 设了 `self.eat_t = 1.0`，但 `paintEvent` 里从没读过它——吃东西没有任何视觉反馈 | Android 版补上了咀嚼式缩放 |
| 天气描述映射 | 原版映射表只有 7 条，雾/雪/阵雨等会直接显示英文 | 补到 20 条，未命中仍回退原文 |
| `eat_t` 递减 | 原版 `tick()` 里同样没有递减 `eat_t`，设了就永远是 1.0 | Android 版正常递减 |
| AI 模型名 | `deepseek-chat` 已停用，照抄必报 404 | 改用 `deepseek-flash` |
| 聊天暂停 | 原版 `chat_paused` 靠 `_click_timer` 与拖拽交错维护，状态易漏 | v1.2 用引擎的 `onDragStart/onDragEnd` 明确暂停移动 |

## 九、v1.2 自己引入又修掉的缺陷（值得记）

| 缺陷 | 现象 | 根因 | 修法 |
|---|---|---|---|
| 面板让路反噬用户设置 | 用户关掉「可互动」后，进出设置面板会被改回开启 | 让设置面板直接写 `config.interactive`，把"面板临时让路"和"用户意图"混在同一字段 | 拆开：面板只用 `PetRuntime.settingsVisible` 标记；服务端 `shouldBeTouchable()` 统一裁决。并新增只刷新 flags、**不写配置**的 `ACTION_REFRESH_TOUCHABLE` |
| 首次引导跳过面板 | 没配 Key 时长按直接跳设置页，用户不知道长按是干嘛的 | `openAiChat()` 里提前 return | 改为**先弹面板**，在面板里给可点击的引导提示 |
