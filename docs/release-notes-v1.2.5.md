# 大肥鱼桌宠 · Android 版 v1.2.5

从 Python / PySide6 桌面版移植而来，Kotlin 原生实现（纯 View + Canvas 绘制，无第三方 UI 库）。目标 Android 8.0+（minSdk 26）。

---

## 安装步骤

1. 下载下方 `dafeiyu-pet-v1.2.5-release.apk`，拷到手机点击安装（首次需允许「安装未知来源应用」）。
2. 打开应用 → 点「授予悬浮窗权限」→ 在系统设置里打开「**允许显示在其他应用上层**」。
   **这步必须做，否则鱼不会出现。**
3. Android 13+ 再点「授予通知权限」。
4. 点「启动桌宠」。

## 本版改动一：AI 变成「原汁原味的大模型」

**反馈**：「对话不要加萌宠提示和字数限制！原汁原味的聪明大模型！！」

之前的系统提示词是我从原 Python 桌宠搬过来的：

```
你是「大肥鱼」，一只住在用户手机上的桌面宠物鲸鱼娘，性格贱兮兮但可爱，
偶尔吐槽主人但不真骂人。不要自称AI或大模型，自然地以大肥鱼的身份说话。
```

**现在整个删掉。** 请求里**完全不带 `system` 消息**，模型以原生人格回答。

对比（同一个问题）：

**v1.2.4（带人设）**
```
（甩甩尾巴）哎呀主人问这么高深的问题，是想考倒大肥鱼吗～不过本鱼虽然圆滚滚的
但还是懂一点的啦！三体纠缠嘛，就是三个量子比特之间产生了那种剪不断理还乱的
纠缠关系（比本鱼和零食的关系还复杂呢）…
```

**v1.2.5（无人设）**
```
The capital of Australia is **Canberra**.
```

干净、直接、带 Markdown 格式 —— 就是大模型本来的样子。

### 回答长度

设置页「**回答长度**」保留两个选项：

| 选项 | 说明 |
|---|---|
| **不限制（默认）** | 完全不加提示词 |
| 简短（40字内） | 对确有需要的人保留 |

## 本版改动二：重做「按住说话」

**反馈**：「你这个'按住说话'功能做的也太简陋了吧，你能不能去网上找找 deepseek 官方 app 的按住说话是怎么实现的」

你说得对。旧版只有一个图标变色加一行状态文字，**没有任何视觉反馈**。

我查了官方行为和通用做法：DeepSeek 官方 App 从 1.6.3 起支持「按住说话」；
主流长按语音交互的约定是 **按住 → 浮层边说边出字 → 波形跟随音量 → 上滑取消 → 松手发送**。

### 新版交互

| 阶段 | 表现 |
|---|---|
| **按住** | 弹出居中圆角浮层，开始收音；麦克风按钮变红 |
| **说话中** | **实时波形**（24 根竖条，跟随音量跳动）；**边说边出字**显示识别中间结果 |
| **上滑** | 超过阈值进入取消态：浮层和波形**变红**，提示变「松开取消」，浮层轻微缩小 |
| **松手** | 正常结束 → 结果写进输入框（可自动发送）；取消态 → 丢弃并提示「已取消」 |
| **松手太快** | 提示「说话时间太短」，不发起识别 |

细节：
- 静音时波形有**呼吸动画**（`onRmsChanged` 只在有声时频繁回调，不补动画会像卡死）
- 浮层是 `FLAG_NOT_TOUCHABLE` 悬浮窗，不吃触摸、不抢焦点
- 取消时不弹错误提示（用户主动行为不是错误）

### 实测验证

| 验证项 | 结果 |
|---|---|
| 浮层弹出 | ✅ 按住时 dafeiyu 窗口数 3 → 4 |
| 浮层渲染 | ✅ 截图确认：圆角浮层 + 蓝色波形 + 「手指上滑，取消发送」 |
| 麦克风按钮激活态 | ✅ 变红 + 🔴 |
| **上滑取消** | ✅ 滑到取消区松手 → 状态显示「已取消」，不发起识别 |
| 触摸事件链路 | ✅ `DOWN → MOVE×N → UP` 全部正常 |
| 崩溃检查 | ✅ 无 `FATAL EXCEPTION` |

> 模拟器没有语音识别服务，识别本身返回 `ERROR_SERVER`。
> 但**整条交互链路（触摸 → 浮层 → 取消手势 → 状态复位）已完整验证**。
> 识别效果请在真机上确认。

| 拖动 | 移动鱼 |

## 其它设置

| 设置项 | 说明 |
|---|---|
| 显示思考过程 | 默认关。开启后思考以灰色斜体气泡显示（响应体积 81KB vs 1.5KB） |
| 语音识别后自动发送 | 默认开。关掉则只填入输入框等你确认 |
| 模型名 | 可填 `deepseek-flash`（快）或 `deepseek-v4-pro`（更聪明） |
