# 大肥鱼桌宠 · Android 版 v1.2.2

从 Python / PySide6 桌面版移植而来，Kotlin 原生实现（纯 View + Canvas 绘制，无第三方 UI 库）。目标 Android 8.0+（minSdk 26）。

---

## 安装步骤

1. 下载下方 `dafeiyu-pet-v1.2.2-release.apk`，拷到手机点击安装（首次需允许「安装未知来源应用」）。
2. 打开应用 → 点「授予悬浮窗权限」→ 在系统设置里打开「**允许显示在其他应用上层**」。
   **这步必须做，否则鱼不会出现。**
3. Android 13+ 再点「授予通知权限」。
4. 点「启动桌宠」。

## 本版重要修复（两个严重 bug）

### 1. AI 对话：键盘弹得出来却打不进字 ✅ 已修

**原因**：v1.2/v1.2.1 的对话界面是一个独立悬浮窗（`TYPE_APPLICATION_OVERLAY`）。
实测发现悬浮窗**能拿到窗口焦点、键盘也能显示，但输入法不会为它建立 InputConnection**：

```
mCurrentFocus          = com.dafeiyu.pet        ← 有焦点
mIsInputViewShown      = true                   ← 键盘显示了
mServedView            = DecorView{...别的Activity}  ← 输入法连的是别的窗口
mServedInputConnection = null                   ← 输入连接为空 → 打字无效
```

这不是加 flag 能解决的，文本输入必须交给有正常窗口令牌的 Activity。

**修法**：对话界面改成**透明浮层 Activity**（Dialog 主题 + 半透明背景 + 底部对齐），
观感与原来的悬浮面板一致。修复后 `mServedInputConnection` 已正常建立。

### 2. 退出对话后整个手机点不动、只能重启 ✅ 已修

**原因**：同样是悬浮窗脱离 Activity 生命周期的问题。一旦没被正确移除就会残留成
"孤儿窗口"，持续拦截全局触摸。

**修法**：Activity 由系统托管生命周期；并在 `onPause` 就复位"对话可见"标记
（早期放在 `onDestroy`，按返回键时不触发，会导致桌宠永久处于触摸穿透状态）。

**顺带修掉**：桌宠窗口现在**永远**保持 `NOT_FOCUSABLE`。早期版本会在对话界面打开时
去掉它，导致桌宠与对话界面抢输入焦点。

## AI 配置

设置页 →「AI 对话」区，两种方式：

- **DeepSeek 预设**（最省事）：地址和模型已填好，只需填 API Key（`sk-…`）
- **自定义**：任意 OpenAI 兼容服务（通义 / 智谱 / Kimi / 本地 ollama 等），填地址、模型、Key

> ⚠️ **注意模型名**：老教程里的 `deepseek-chat` / `deepseek-reasoner` **已于 2025-07-24 停用**，
> 现在用会报错。当前模型是 `deepseek-flash` 和 `deepseek-v4-pro`。

填完可点「测试连接」验证配置是否正确。

## 已知限制

- **开机自启容易被国产 ROM 拦截**，需在系统「自启动管理」里放行。
- **系统可能杀掉悬浮窗服务**，建议加入电池优化白名单。
- 拿不到 PC 那套 CPU / 内存 / GPU 温度指标，改成了低电量提醒。
- 对话界面的软键盘在真实手机上未做完整验证（模拟器装不了中文输入法），
  但输入连接已确认建立。若有问题请提 Issue。
