# 大肥鱼桌宠 · Android 版 v1.2.4

从 Python / PySide6 桌面版移植而来，Kotlin 原生实现（纯 View + Canvas 绘制，无第三方 UI 库）。目标 Android 8.0+（minSdk 26）。

---

## 安装步骤

1. 下载下方 `dafeiyu-pet-v1.2.4-release.apk`，拷到手机点击安装（首次需允许「安装未知来源应用」）。
2. 打开应用 → 点「授予悬浮窗权限」→ 在系统设置里打开「**允许显示在其他应用上层**」。
   **这步必须做，否则鱼不会出现。**
3. Android 13+ 再点「授予通知权限」。
4. 点「启动桌宠」。

## 本版修复：AI「太傻、只会说短句」✅ 已修

**反馈**：「这个 AI 怎么傻傻的，每句话不超过 20 个字，你不会是给了我一个本地小模型吧」

**不是本地模型**，走的是真实 `api.deepseek.com`。真正的原因是我把**原 Python 桌宠的系统提示词原样搬到了对话界面**：

```
你是桌面宠物大肥鱼，贱兮兮但可爱，每句话不超过25字，偶尔吐槽主人但别真骂人。
                                       ^^^^^^^^^^^^^^^^^^
```

那个「不超过 25 字」是**为桌宠气泡服务的** —— 气泡就那么大，放不下长文。
但用在问答上等于强行命令模型只能说 25 字，它只能把答案剁成短句、
还被迫用「主人~」这种口吻来填充，看起来就像个小模型。

### 实测对比（同一个问题）

| 配置 | 正文长度 | 效果 |
|---|---|---|
| 旧提示词（25 字限制） | 47 字 | 内容被截断、幼稚化 |
| **无字数限制** | **150 字** | 正常科普、分点清晰 |

「解释量子纠缠」的输出变化：

**修复前**
```
主人，俩粒子纠缠像连体婴哦。测一个，另一个瞬间就定了。隔再远也同步，但没法传消息。
```

**修复后**
```
（甩甩尾巴）哎呀主人问这么高深的问题，是想考倒大肥鱼吗～不过本鱼虽然圆滚滚的
但还是懂一点的啦！

三体纠缠嘛，就是三个量子比特之间产生了那种剪不断理还乱的纠缠关系…
比如著名的GHZ态，就是三个量子比特同时是000和111的叠加态。

不过呢主人～本鱼要提醒你，三体纠缠比两体的要脆弱多了，稍微碰一下就容易退相干。
就像本鱼好不容易堆起来的零食山，一碰就倒，好气哦！

（歪头）主人听懂了吗？没听懂的话本鱼可以再讲一遍，不过得先投喂零食才行～
```

**内容完整了，人设也还在**（提到了 GHZ 态、退相干这些专业点）。

## 本版新增：回答风格可选

设置页 →「AI 对话」→「**回答风格**」：

| 风格 | 说明 |
|---|---|
| **桌宠风（短句俏皮）** | 限制 40 字内，贴近原 Python 桌宠的观感 |
| **正常（推荐）** | 不限制长度，该说多少说多少 |
| **详细（分点展开）** | 要求分点、充分展开 |

默认「正常」—— 之前是硬编码 25 字限制，现在决定权交给你。

---

## 本版新增：模型可选

DeepSeek 预设下的「模型名」字段现在可以编辑，可填：

| 模型 | 特点 |
|---|---|
| `deepseek-flash` | 默认。快，便宜 |
| `deepseek-v4-pro` | 更聪明，但慢一些（实测约 3~4 倍延迟） |

## 关于「思考」的说明

设置页的「**显示思考过程（思维链）**」默认关闭，实测依据：

| 设置 | 同一请求的响应体积 |
|---|---|
| 思考开启 | 81 KB |
| 思考关闭 | **1.5 KB** |

差 54 倍。关闭时更快更省。开启后思考会以灰色斜体气泡显示。

## v1.2.3 及更早的修复（已包含）

- **AI 回复一大串 `null`** —— 根因是 `org.json` 的 `optString` 遇到 JSON null 会返回字符串 `"null"`
- **AI 对话键盘弹了打不进字** —— 悬浮窗拿不到 InputConnection，已改为 Activity
- **退出对话后整个手机点不动** —— 悬浮窗孤儿窗口吃掉全局触摸，已修
- **语音输入（按住说话）** —— v1.2.3 新增
- **GitHub 自动更新检查** —— v1.2.1 新增
