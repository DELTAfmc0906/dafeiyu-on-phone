# 大肥鱼桌宠 · Android 版 v1.4.0

从 Python / PySide6 桌面版移植而来，Kotlin 原生实现。目标 Android 8.0+（minSdk 26）。

**本版修复你反馈的三个问题：文字重合、桌宠透明失去响应、语音输入卡顿。**

---

## 安装步骤

1. 下载 `dafeiyu-pet-v1.4.0-release.apk` 安装（首次需允许「安装未知来源应用」）。
2. 打开 → 点「授予悬浮窗权限」→ 在系统设置里打开 **「允许显示在其他应用上层」**。
3. Android 13+ 再授予通知权限。
4. 点「启动桌宠」。

## 一、文字重合 —— 根因是系统字体缩放

诊断你的手机时发现关键设置：

```
font_scale = 1.25        ← 系统字体放大到 125%
```

而**气泡文字的高度和字号是绑定算的，完全没考虑字体缩放**：

```kotlin
bubbleReserve = petHeight * 0.34      // 气泡预留高度
textSize      = bubbleReserve * 0.26  // 字号
```

Android 会按 `fontScale` 再放大 `Paint.textSize`。字体调到 125% 后，
**文字比预留空间大 25%**，装不下就溢出到宠物本体上 —— 就是你看到的"重合"。

更糟的是绘制时没有兜底：

```kotlin
val by = (areaH - bh - ...).coerceAtLeast(0f)   // 压不住就画到界外
```

### 修法（两层）

1. **预留高度跟着字体缩放走**：`bubbleReserve` 也乘 `fontScale`，
   让"预留空间"和"实际文字"同步增长。运行期间系统改字体也会重新同步。
2. **按可用空间自适应收缩字号**：先按理想字号排版，放不进预留区就把字号乘 0.86
   重排，最多迭代 4 次（最低约 55% 字号）。
   **这样无论系统字体设多大，气泡都一定装得下** —— 不再是"压不住就画出去"。

顺带把「按住说话」椭圆条和输入行的固定高度改成 `minHeight + wrap_content`，
圆角按实际高度动态计算（保证仍是正椭圆）。

### 验证

把模拟器字体调到 **1.25** 复现你的机器条件后测试：设置页布局正常，无重合。

## 二、对话打开时桌宠透明 + 失去响应

**根因**：`applyInteractive()` 里有一句

```kotlin
val touchable = shouldBeTouchable() && !PetRuntime.chatVisible
```

只要对话打开就强制让鱼 `NOT_TOUCHABLE`。而 Android 对
**「不可触摸 + alpha > 0.8」的悬浮窗会自动把 alpha 压到 0.8**
（WindowManager 的既定行为），所以鱼看起来变透明了，同时也点不动 —— 正是你描述的现象。

**那句话的前提已经过时了**：v1.2.2 写它时，对话界面是画在鱼自己窗口里的一个面板，
两者确实重叠；而现在对话界面是**独立的 Activity 窗口**，系统会让它浮在悬浮窗之上，
鱼并不会挡住它。

**修法**：去掉 `chatVisible` 这个条件 —— 只在真正需要让路时穿透
（用户关了可互动、或设置面板在前台），并显式 `lp.alpha = 1f` 避免被误判。

### 验证

```
对话打开时：
  穿透 = 否 ✓ 可互动
  桌宠完全不透明（对比之前 alpha=0.800 的半透明）
```

## 三、语音输入卡顿

### 3.1 预热识别服务（降延迟）

`SpeechRecognizer` 第一次 `startListening` 要先**绑定服务、建连接** ——
这一步在按住说话时是纯等待，感觉就是"卡一下"。

现在对话界面一打开就预热绑定，用户真正按住时服务已连好，几乎立即生效。
开销可控：只创建一次，不启动录音（不占麦克风、状态栏无录音指示）。

### 3.2 改掉一个帮倒忙的参数

早期为了"别在用户思考时断掉"，把静音超时设成 60 秒：

```kotlin
EXTRA_SPEECH_INPUT_COMPLETE_SILENCE_LENGTH_MILLIS = 60000
```

实测发现**多数识别引擎把它当成"最长等待"**，反而让结果迟迟不回 ——
松手后要等好几秒才出字，体感就是"卡"。

现在**不设这个值**：结束时机完全由我们自己在松手时 `stopListening()` 控制，
不需要靠超时兜底。只留一个较短的最小语音长度，避免把咳嗽当输入。

### 3.3 关于离线识别（重要发现）

我在你手机上做了实测，**真凶在小米这边**：

```
AsrService: onStartListening: useLocal=false        ← 小米没走本地
AsrService: network available, startAudioInput       ← 转了网络
```

你的手机上**只有一个标准识别服务**：

```
#0  com.xiaomi.mibrain.speech/.asr.AsrService   ← 默认，但只支持在线
#1  com.anthropic.claude/...ClaudeRecognitionService
```

讯飞、百度输入法虽然装了，但用的是**私有协议**（`com.iflytek.inputmethod.speech`），
不注册标准 `RecognitionService` 接口，系统 API 选不到。

**所以最终解法是下载小米的离线语音包**（设置 → 小爱同学 → 语音识别 →
离线语音识别 → 下载中文包）。下载后 `useLocal` 才会变 true，本 App 会自动用上。

v1.3.4 起设置页会**显示你的实际识别服务名 + 下载指引**，不再是干巴巴一句"不支持"。
