# 大肥鱼桌宠 · Android 版

> 从 Python / PySide6 桌面版移植而来。Kotlin 实现，纯原生 View + Canvas 绘制，无第三方 UI 库。
>
> 移植日期：2026-10-13　|　目标：Android 8.0+（minSdk 26）

## 一、安装与首次配置

### 1. 安装 APK

把 `dist\大肥鱼桌宠-v1.2-release.apk` 拷到手机，点击安装。
（首次安装需在系统里允许"安装未知来源应用"。）

### 2. 授予悬浮窗权限 ← **必须，否则鱼出不来**

打开应用 → 点「授予悬浮窗权限」→ 在系统设置里找到「大肥鱼桌宠」→ 打开「允许显示在其他应用上层」。
Android 没有运行时弹窗能申请这个权限，只能手动开。

### 3. 授予通知权限（Android 13+）

点「授予通知权限」，允许即可。通知栏是控制桌宠的主入口。

### 4. 启动

点「启动桌宠」。鱼会出现在屏幕右下角。

### 5. 配置 AI（想跟鱼聊天才需要）

两种方式，任选：

- **首次长按鱼身** → 弹出对话面板 → 点里面的「还没设置 API Key，点这里去设置」→ 跳到设置页的 AI 区
- **直接进设置页** → 滚到最下面「AI 对话（长按鱼身唤醒）」

填法见第五节。

## 二、怎么操作

### 对鱼本身

| 操作 | 效果 | v1.2 变动 |
|---|---|---|
| **拖动** | 把它拖到任意位置（会侧身朝向拖动方向） | 不变 |
| **单击** | 蹦跳 + 回嘴一句 | 不变 |
| **长按** | **唤醒 AI 对话** | 🆕 原来这里弹菜单 |
| **双击** | 弹设置菜单 | ⬅️ 从长按移过来 |
| **三指轻点** | 弹出喂食面板（🐟🍰🍭🍡💎） | ⬅️ 从双击移过来 |

> 三指轻点：三根手指同时点一下鱼身。单指双击仍是设置菜单。

### 设置菜单（双击鱼身）

- **模式**：自由散步 / 跟随手指 / 原地待着
- **大小**：**滑杆自由调节，范围屏高 8%~50%**（v1.1）。另有三档快捷值：小 10% / 中 20% / 大 34%
- **查看天气**：查询设置的城市天气，鱼会气泡播报
- **不可互动 / 恢复可互动**：不可互动时触摸穿透到下面的应用，**想改回来就点通知栏的「可以摸它」**
- **低电量提醒**：开关
- **回到屏幕内**：鱼跑到屏幕外时救回来
- **开机自启**：开关
- **收工**：关闭桌宠

### 调大小（v1.1 起）

两个入口，都是**拖动即时生效**，松手即保存：

1. **设置面板** → 「大小」区 → 拖滑杆，或点小/中/大三档快捷按钮
2. **双击鱼身** → 菜单里点「大小：占屏高 xx%」→ 弹滑杆

| 档位 | 占屏高 | 1080×2424 屏上的实际高度 |
|---|---|---|
| 最小 | 8% | 约 193px（约 46dp，很小但看得清） |
| 小 | 10% | 约 242px |
| 中（默认） | 20% | 约 484px |
| 大 | 34% | 约 824px |
| 最大 | 50% | 约 1212px |

> **省地方建议拉到 8%~10%**。v1.0 的最小档是 18%，v1.1 的最小档只有它的一半不到。
>
> 另外：**打开设置面板时，鱼会自动变成触摸穿透**，这样即使鱼很大也不会挡住面板控件；
> 离开面板后自动恢复你原本的「可互动」设置。

### 通知栏（常驻）

三个按钮：**设置** / **摸不到它·可以摸它**（切换可互动）/ **收工**

## 二·五、AI 对话（v1.2 新增）

长按鱼身 → 弹出底部对话面板 → 打字 → 发送。**Ask 模式**（纯问答，不含 Agent/工具调用）。

面板里有：标题栏（清空 / 关闭）、对话记录（你的消息靠右蓝色，鱼的回复靠左白色）、
底部输入框与发送按钮。鱼的回复会**流式显示**（边生成边冒字），同时用气泡说一句摘要。

对话历史保留最近 **40 条**（与原 Python 版一致），存在本地，重开应用还在。点「清空」可清除。

### 配置 API

设置页 →「AI 对话（长按鱼身唤醒）」区。两种模式：

**A. DeepSeek 预设（最省事）**

地址和模型已自动填好、不可编辑，**只需填 API Key**：

| 项 | 值 |
|---|---|
| 接口地址 | `https://api.deepseek.com/v1` |
| 模型名 | `deepseek-flash` |
| API Key | `sk-…`（去 platform.deepseek.com 申请） |

> ⚠️ **注意模型名**：网上很多老教程还写 `deepseek-chat` 或 `deepseek-reasoner`，
> 这两个名字**已于 2025-07-24 停用**，现在用会报错。
> V4 时代的模型是 `deepseek-flash` 和 `deepseek-v4-pro`。
> 来源：[DeepSeek API 官方文档](https://api-docs.deepseek.com/)

**B. 自定义（任意 OpenAI 格式兼容服务）**

预设切到「自定义（OpenAI 格式）」，然后自己填三项：

| 项 | 说明 | 示例 |
|---|---|---|
| 接口地址 | 服务的 base url | `https://api.moonshot.cn/v1`、`http://192.168.1.5:11434/v1` |
| 模型名 | 该服务的模型标识 | `kimi-k2`、`qwen-max`、`llama3` |
| API Key | 该服务的密钥 | 各家格式不同 |

地址**容错**，下面这些写法都能用（程序会自动补 `/chat/completions`）：

```
https://api.deepseek.com
https://api.deepseek.com/v1
https://api.deepseek.com/v1/
api.deepseek.com                        ← 会自动补 https://
https://api.deepseek.com/v1/chat/completions   ← 已完整，原样使用
```

通义千问、智谱、Kimi、本地 ollama / vLLM 等只要兼容 OpenAI 的 `/chat/completions` 都能接。

### 测试与排错

设置页 AI 区有「**测试连接**」按钮，会发一句最简请求验证 Key / 地址 / 模型是否可用，
结果直接用 Toast 告诉你。

常见错误提示（都是中文，直接可读）：

| 提示 | 原因 |
|---|---|
| `请先设置 API Key` | Key 没填 |
| `Key 无效或没权限` | Key 错、过期、或没开通 |
| `地址或模型名不对` | 404，通常是模型名写错（比如用了已停用的 `deepseek-chat`）|
| `请求太频繁，歇会儿` | 429 限流 |
| `请求超时，检查网络` | 网络不通或首字延迟太长 |
| `连不上服务器，检查网络` | DNS 解析失败 |
| `接口没有返回内容（可能不支持 stream）` | 该服务不支持流式返回 |

### 隐私说明

- API Key 存在本机 SharedPreferences，**不会上传到任何第三方**，只用于直连你自己配置的服务
- 对话内容直接发给该 API 服务商，不经过其他中转
- `key.properties`（应用签名口令）在工程目录里，**别外传**

## 五、已知限制

这些不是 bug，是 Android 平台的限制：

1. **开机自启容易被拦**。小米 / 华为 / OPPO / vivo 等 ROM 默认拦截开机广播。
   需要在系统的「自启动管理」里给本应用放行。代码层面无法绕过。

2. **系统可能杀掉悬浮窗服务**。省电模式、后台清理都会。已用前台服务 + 常驻通知尽量保活，
   但仍建议在系统设置里把本应用加入「电池优化白名单 / 后台运行白名单」。

3. **拿不到 PC 那套系统指标**。原版监控 CPU / 内存 / NVIDIA 显卡温度；
   Android 普通应用读不到这些，改成了低电量提醒 + 充电恢复提醒。

4. **「跟随手指」的实际含义**。PC 版跟随鼠标指针；手机没有指针，
   改成跟随你最后一次触摸屏幕的位置——摸一下别处，鱼就会往那边挪。

## 六、故障排查

| 现象 | 处理 |
|---|---|
| 点「启动桌宠」没反应 | 悬浮窗权限没给。设置面板顶部的状态栏会显示「悬浮窗 ✗」 |
| 鱼不见了，但通知还在 | 双击菜单选「回到屏幕内」；或停止再启动 |
| 摸不到鱼 | 之前切到了「不可互动」。点通知栏按钮切回来 |
| **鱼太大挡住设置面板** | v1.1 起已自动处理：面板打开时鱼会触摸穿透 |
| 长按鱼没弹出 AI 面板 | 检查设置页「启用 AI 对话」是否开着；若鱼处于「不可互动」也点不到 |
| AI 提示「地址或模型名不对」 | 多半是模型名写错。**别用已停用的 `deepseek-chat`**，改用 `deepseek-flash` |
| 通知栏没有按钮 | Android 13+ 未授予通知权限 |
| 鱼卡住不动 | 可能系统冻了服务。通知栏「收工」再「启动桌宠」 |
| 天气查不出来 | 检查网络；城市名用中文，如「汕头」 |
| 调小了但鱼位置跑到屏幕外 | 双击菜单「回到屏幕内」；引擎改尺寸时已尽力夹取边界 |
